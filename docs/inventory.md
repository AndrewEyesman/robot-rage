# Director feature inventory

Every Director feature the game's Lingo uses, checked against dirplayer. Generated by
`tools/inventory-report.py` from `docs/inventory.json`. Don't edit by hand: change an
entry in the JSON (or `tools/inventory-overrides.json`) and re-run.

Names come from `tools/lingo-inventory.py` over the decompiled scripts (all movies,
including the fan wrappers). Each was classified by reading how the game uses it and
how dirplayer implements that use, against Director's documentation and ScummVM's
Director engine for 2D. `works` therefore means "matches the documentation as far as
code reading can tell", not "proven against Adobe's player". Items marked
**needs Adobe** are to be settled with Ghidra. `fixed` means fixed and tested since.
